# KITV

KITV 是基于 [FongMi/TV](https://github.com/FongMi/TV) 的个人定制版影视应用，电视、手机都能用，另有一个内置代理的电视代理版。

下载见 [Releases](https://github.com/florakiki/KITV/releases)。

## 三个版本

| 版本 | 包名 | 应用名 | 适用设备 |
| --- | --- | --- | --- |
| 电视正式版 | `com.kitv.tv` | KITV | Android TV / 电视盒子 |
| 手机正式版 | `com.kitv.tv` | KITV | 手机 / 平板 |
| 电视代理版 | `com.kitv.tv.proxy` | KITV代理版 | 电视专用，内置代理核心 |

三个版本互相独立，代理版包名不同，可以和电视正式版装在同一台电视上共存。

## 共同功能

### 点播

- 多站源、分类筛选、跨站搜索、换源
- 收藏、播放记录、无痕模式
- 配置 URL 直接填 `.json`、`.js`、`.py` 都行，不用再包一层
- 自己的配置可以 AES 加密，只有 KITV 能打开，别人的壳播不了；别人的明文配置照常能播（见下方“配置加密”）

### 直播

- 分组选台、频道收藏、线路切换
- 节目表（EPG 时间轴）：当前分组、当前整点起 6 小时，正在播的节目加粗显示，点节目直接切台
- 支持备用直播源

### 播放

- 倍速、字幕、弹幕（自动弹出，自研渲染器）
- 进度条拖动定位
- 画中画、背景音频

### 遥控与互通

- 网页遥控：手机浏览器扫码连接，远程输入、推送配置
- 点播设置弹窗里嵌了二维码（远程输入），扫码就能在手机上打字
- 远程保存：手机上配好点“保存”，电视自动确认，点播里直接能用，不用再拿遥控按确定

### 更新

- 应用内检查更新，自动选最快的 GitHub 下载代理
- 每个版本只认自己的安装包，不会下错（电视正式版、手机正式版、电视代理版各认各的文件名）

## 电视正式版

- 遥控器操作，焦点优化：首页顶栏、底部控制栏、直播换台上下键
- 默认：图片尺寸“小”，关闭点播“关”
- 直播节目表按钮排在控制栏第一位
- 点播配置失败时显示原因和重试按钮

## 手机正式版

- 底部导航：点播 / 直播 / 设置
- 默认：图片尺寸“大”，关闭点播“开”
- 语音搜索
- 运行包内置（Python + QuickJS），不用再下载模块；模块管理入口已去掉

## 电视代理版（KITV代理版）

电视正式版的功能都有，另外内置代理，适合有的爬虫站需要走梯子才能用的情况。

- 内置 [sing-box](https://github.com/SagerNet/sing-box) v1.14.4 核心，本地代理 `127.0.0.1:7890`，只给本机爬虫用，不对外开放
- 订阅链接自己填（支持 3 条）：Base64、Clash YAML、SingBox JSON、明文链接都能自动识别
- 也支持手动一条一条加节点
- 节点默认自动选最快的，节点死了自动换线；也可以手动指定某一个节点
- 测速按真实下载速度（MB/s）从快到慢排，名字后面直接显示速度，不再看延迟
- 首页 logo 就是代理开关：点一下开、再点一下关，开着时 logo 旁有绿点；长按 logo 进代理设置
- 直播跟随代理开关：有的台要走代理、有的不用，按台开关
- 网页遥控里也有专门的代理设置页
- 正式版（电视、手机）不带代理，只有代理版有

## 配置加密

- AES-256-CBC，加密文件以 `KITV-AES:` 开头
- 自己的 `ki.json` / `kiki.txt` 加密后只有 KITV 能读，别的壳打不开
- KITV 仍能正常读别人的明文配置
- 密钥在 App 内，反编译能拿到，防君子不防小人
